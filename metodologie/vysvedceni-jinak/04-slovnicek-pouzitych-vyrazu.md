# 4. Slovníček použitých výrazů

*Zdroj: https://vysvedcenijinak.ped.muni.cz/metodika/slovnicek*

Slovníček vysvětluje význam použitých výrazů v kontextu metodiky. Je určen všem, kteří se zapojují do experimentálního vývoje nového vysvědčení a usilují o změnu procesu implementace formativního hodnocení v praxi.

| Výraz | Vymezení |
|---|---|
| **dovednost** | učením získaná dispozice ke správnému, rychlému a úspornému vykonávání určité činnosti vhodnou metodou |
| **hodnocení individualizované** | neporovnává žáky mezi sebou, ale výkon žáka je posuzován vzhledem k předešlému výkonu, individualitě a jeho specifickým schopnostem |
| **hodnocení jako učení** | žáci jsou vedeni k reflexi svého procesu učení a vrstevnického hodnocení; součástí je reflektování podaného výsledku učení a budování kompetence k učení |
| **hodnocení pro učení** | průběžně poskytovaná zpětná vazba k procesu učení žáků, která je řízena vyučujícími v interakci s žáky |
| **hodnocení učení** | hodnocení výsledků učení žáků po skončení stanoveného období |
| **holistický přístup** | celostní přístup k žáku zaměřený na kognitivní, osobnostní a sociální rozvoj |
| **chování** | souhrn vnějších projevů, činností, jednání a reakcí jedince |
| **integrace vzdělávacího obsahu** | propojení vzdělávacího obsahu na úrovni témat a vzdělávacích oborů |
| **klíčové kompetence** | souhrn vědomostí, dovedností, schopností, postojů a hodnot důležitých pro osobní rozvoj |
| **komplexně rozvíjející hodnocení** | všechny hodnoticí aktivity reflektující proces učení a vyučování |
| **očekávané výstupy** | stěžejní část vzdělávacího obsahu, ověřitelné a prakticky zaměřené |
| **popisný jazyk** | neposuzující verbální popis situace bez přívlastků |
| **posuzující jazyk** | slovní vyjádření ohodnocení a klasifikace |
| **rámcové vzdělávací programy** | kurikulární dokumenty státní úrovně |
| **Rámcový vzdělávací program pro základní vzdělávání** | kurikulární dokument normativně stanovující rámec pro základní vzdělání |
| **školní hodnocení** | zahrnuje hodnocení procesu učení i výsledků vzdělávání |
| **školní vzdělávací programy** | kurikulární dokumenty školní úrovně |
| **školský zákon** | zkrácený název pro zákon č. 561/2004 Sb. |
| **tematický plán** | prostředek k sestavování časového plánu výuky |
| **teoretické předměty** | předměty ze vzdělávacích oblastí Jazyk, Matematika, Informatika, Člověk a jeho svět, Člověk a společnost, Člověk a příroda |
| **učivo** | součást vzdělávacího obsahu strukturovaného do tematických okruhů |
| **výchovné předměty** | předměty ze vzdělávacích oblastí Umění a kultura, Člověk a zdraví, Člověk a svět práce |
| **výsledky vzdělávání** | úroveň osvojení očekávaných výstupů |
| **vyučovací předmět** | forma didaktického uspořádání vzdělávacího obsahu |
| **vzdělávací oblasti** | orientačně vymezené celky vzdělávacího obsahu |
| **vzdělávací obory** | samostatné části vzdělávacích oblastí v RVP |
| **vzdělávací obsah** | vymezení očekávaných výstupů a učiva |
| **základní vzdělávání** | vzdělávání realizované na úrovni primární a nižší sekundární školy |
